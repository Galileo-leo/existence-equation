# EP8: High-Drive Response of a Topological Closure

This directory contains the production scripts for EP VIII of the
Existence Equation project.  The experiments test whether a localized
topological closure driven by a same-field Gaussian wave packet can
produce a structured high-drive response hierarchy without imposing
strong-field machinery such as SFA, Volkov states, transition matrices,
or external coupling Hamiltonians.

## Files

- `08_vortex_2d_v3_2.py`  
  Canonical epsilon scan on a `256 x 256`, `L = 60` periodic domain.
  Sweeps ten drive amplitudes from `epsilon = 0.25` to `1.00`, extracts
  nonlinear residuals, region-resolved power, angular momentum-space
  diagnostics, and the Goldilocks score `G_k`.  Produces Figures 1-6
  and Table I of the paper.

- `09_robustness_v4_0.py`  
  Geometry robustness scan over five `(k0, sigma)` packet configurations.
  Tests whether the regime ordering survives changes in packet momentum
  and spatial overlap.  Computes `Z_Phi`, `G_k`, depletion/emission
  boundaries, and the drive ratio `chi = E_packet / E_closure`.
  Produces Table II and robustness summary figures.

- `10_resolution_512_v1_2.py`  
  Matched-registration domain-size test.  Compares the canonical
  `256 x 256`, `L = 60` run with a `512 x 512`, `L = 120` run at the
  same lattice spacing `dx = 0.234375`.  The test checks whether
  normalized diagnostics remain stable when the domain is doubled at
  fixed registration scale.  Produces Figure 7 and Table III.

## Physical Setup

All three scripts solve the two-dimensional Existence Equation

```text
(1/c^2) Psi_tt = nabla^2 Psi + lambda Psi - alpha |Psi|^2 Psi
```

with `lambda = alpha = c = 1`.  The closure is a relaxed winding-one
vortex, and the drive is a Gaussian same-field wave packet initialized
with the ED linear dispersion relation.

The central diagnostic is the phase-aligned nonlinear residual

```text
Psi_res = Psi_full - Psi_vortex - Psi_packet + Psi_vac
```

which vanishes for a linear superposition and therefore isolates the
finite-time nonlinear cross-response between the closure and the packet.

## Main Result

The canonical scan resolves four drive regimes:

1. Weak response below the bound-sector depletion threshold.
2. Phase ordering, where the bound-sector order parameter `Z_Phi` peaks.
3. Structured residual emission, where the momentum-angular score `G_k`
   peaks.
4. Overdriven topological rearrangement, where the original winding is
   no longer preserved.

In the canonical configuration, the ordering is approximately

```text
epsilon_dep < epsilon_coh < epsilon_em < epsilon_topo
0.25        < 0.50        < 0.70       < 0.90
```

The result is intended as an existence proof for a structured high-drive
response hierarchy generated by the cross-response algebra of a single
nonlinear field.

## Running

Each script is standalone:

```bash
python 08_vortex_2d_v3_2.py
python 09_robustness_v4_0.py
python 10_resolution_512_v1_2.py
```

The simulations are computationally heavy and write figures/data files
into the current working directory.
