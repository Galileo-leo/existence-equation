## Key Results

- **Integer spectrum:** eigenvalues of C = i[O₀, O₁] are exactly integers (deviation < 10⁻¹⁴) for L = 3–12
- **Pell–Lucas trace law:** Tr(C²) = L · Q_{L-2}, verified exactly for all L = 3–12
- **NOT su(2):** Casimir diagnostic shows emergent algebra is not isomorphic to su(2)
- **Random projection control:** random subspace → non-integer eigenvalues (deviation ~ 0.5)
